## Instructions for Report Sub-agent

When generating the report from this template:

1. **Read all walk reports**: `docs/ux-walker/stories/STORY-*/walk-report.md`
2. **Read all findings**: `docs/ux-walker/stories/STORY-*/findings.json`
3. **Read fix reports**: `docs/ux-walker/fixes/*.md`
4. **Read issues-filed.md**: `docs/ux-walker/issues-filed.md`
5. **Read run-history.json**: `docs/ux-walker/run-history.json`
6. **Aggregate** findings by severity and category
7. **Identify patterns** — look for the same rubric criterion failing across multiple stories
8. **Rank recommendations** by how many stories they would improve
9. **Write** the filled template to `docs/ux-walker/latest-report.md`
10. **Update run-history.json** with this run's summary
